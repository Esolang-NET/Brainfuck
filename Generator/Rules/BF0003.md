# BF0003: Unsupported parameter type

## Cause
The method contains a parameter of an unsupported type.

## Solution
Ensure all parameters are of a supported type:
- `string`
- `System.IO.TextReader`
- `System.IO.PipeReader`
- `System.IO.TextWriter`
- `System.IO.PipeWriter`
- `System.Threading.CancellationToken`
- `Microsoft.Extensions.Logging.ILogger`
- `Microsoft.Extensions.Logging.ILogger<T>`

## Example

```cs
partial class Sample
{
    // Incorrect: int is not a supported parameter type
    [GenerateBrainfuckMethod("+")]
    public static partial void Invalid(int param);
}
```
