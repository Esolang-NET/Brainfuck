# BF0002: Unsupported return type

## Cause
The method's return type is not supported by the Brainfuck source generator.

## Solution
Change the return type to one of the supported types:
- `void`
- `int`
- `string` / `string?`
- `System.Threading.Tasks.Task`
- `System.Threading.Tasks.Task<int>`
- `System.Threading.Tasks.Task<string>` / `System.Threading.Tasks.Task<string?>`
- `System.Threading.Tasks.ValueTask`
- `System.Threading.Tasks.ValueTask<int>`
- `System.Threading.Tasks.ValueTask<string>` / `System.Threading.Tasks.ValueTask<string?>`
- `System.Collections.Generic.IEnumerable<byte>`
- `System.Collections.Generic.IAsyncEnumerable<byte>`

## Example

```cs
partial class Sample
{
    // Incorrect: double is not supported
    [GenerateBrainfuckMethod("+")]
    public static partial double Invalid();
}
```
