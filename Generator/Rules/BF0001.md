# BF0001: Invalid value parameter

## Cause
The `GenerateBrainfuckMethodAttribute` is used without providing the required `source` argument (either as an explicit parameter or via explicit named arguments), or the provided value is null or empty.

## Solution
Ensure a valid, non-empty source string is passed as the first argument to the attribute.

## Example
```cs
// Incorrect: Missing source argument
[GenerateBrainfuckMethod]
public static partial void Invalid();

// Correct
[GenerateBrainfuckMethod("[-]")]
public static partial void Valid();
```
