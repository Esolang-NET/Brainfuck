# BF0005: Unsupported parameter pattern

## Cause
The method uses an unsupported combination of input parameters (allowed: one of `string`, `PipeReader`, or `TextReader`).

## Solution
Use only one input mechanism per method.

## Example

```cs
partial class Sample
{
    // Incorrect: string and PipeReader cannot be combined
    [GenerateBrainfuckMethod(",")]
    public static partial void Invalid(string input, System.IO.Pipelines.PipeReader pipe);
}
```
