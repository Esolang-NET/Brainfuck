# BF0006: Return type and output parameter conflict

## Cause
The output parameter type cannot be combined with the return type.

## Solution
Change the return type or the output parameter to avoid conflicts.

## Example

```cs
partial class Sample
{
    // Incorrect: string return and PipeWriter output parameter conflict
    [GenerateBrainfuckMethod(".")]
    public static partial string Invalid(System.IO.Pipelines.PipeWriter output);
}
```
